# Bidra til Hellemyr FAU

Forslag, feilrapporter og pull requests er velkomne.

1. Lag en egen gren, eller en fork hvis du ikke har skrivetilgang.
2. Gjør en avgrenset endring og kontroller den lokalt.
3. Åpne en pull request mot `main`. Beskriv hva som endres og hvordan det er kontrollert.
4. Be den andre vedlikeholderen gjennomgå endringen før den merges.

Ved synlige endringer: sjekk både mobil og stor skjerm, og legg gjerne ved
skjermbilder. Bruk bare oppdiktede data ved testing av admin og skjema.

Ikke legg inn meldinger fra foreldre, interne notater, tokens, passord eller
private dataeksporter i commits, issues, pull requests eller skjermbilder.
Ved mulig datalekkasje eller sikkerhetsfeil: kontakt vedlikeholderne privat
før detaljer publiseres. Ikke test mot ekte saker i produksjon.

GitHub Pages publiseres fra `main` etter beståtte kontroller når oppsettet er klart.
Cloudflare Worker og migreringer publiseres manuelt fra gjennomgått kode.
Se [DRIFT.md](DRIFT.md).
